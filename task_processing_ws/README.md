# Task Assignment

Tasks will of the form [x1, x2, x3] 
where x1, x2 and x3 are integers

x1 : Task type, x2 : Task object, x3 : Task Location

    *x1 = 1 : Bring object of type x2 to location x3*
    *x1 = 2 : Interact/Inspect object of type x2 at location x3*
    *x1 = 3 : Find object of type x2 (assuming object of type x2 is not present)*
